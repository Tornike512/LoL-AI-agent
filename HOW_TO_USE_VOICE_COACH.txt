====================================================================
   KATARINA AI VOICE COACH - READY TO USE! 🔊
====================================================================

Your AI coach can now SPEAK to you while you play League of Legends!

====================================================================
QUICK START (2 minutes)
====================================================================

1. Install the voice library:

   pip install pyttsx3

2. Test that voice works:

   python test_voice.py

   (You should hear 9 test messages)

3. Start a League of Legends game as Katarina
   (Practice Tool recommended for first try)

4. Run the AI coach:

   python katarina_coach.py

5. Play and LISTEN!

   The coach will speak to you:
   🔊 "Use Q"
   🔊 "Use E, Shunpo"
   🔊 "Use ultimate"
   🔊 "Back and buy"

====================================================================
WHAT TO EXPECT
====================================================================

✅ Voice predictions every 2 seconds
✅ Clear, concise commands
✅ Cooldown warnings
✅ Confidence-based suggestions
✅ Text output in terminal (backup)

====================================================================
TROUBLESHOOTING
====================================================================

No voice?
→ Run: python test_voice.py
→ Check system volume
→ Try running as administrator
→ Use --no-voice flag for text-only

Voice too fast/slow?
→ Edit katarina_coach.py line ~258
→ Change rate from 175 to 150 (slower) or 200 (faster)
